# تشغيل الوكيل الذكي المتكامل بنموذج مفتوح المصدر

هذا الدليل يشرح طريقة تشغيل وكيل المنصة الذكي باستخدام نموذج مفتوح المصدر عبر endpoint متوافق مع OpenAI.

## الفكرة

المنصة أصبحت تحتوي على طبقة وكيل موحدة:

- وكيل القبول والتسجيل
- المشرف الذكي الأكاديمي
- وكيل الامتحانات والقياس
- وكيل البحث والمناقشة
- وكيل الشهادات والتحقق
- وكيل الإدارة والجودة
- وكيل الوكالة والاعتماد
- وكيل الدعم العام

المشرف الذكي لم يُلغَ، بل أصبح شخصية أكاديمية داخل الوكيل العام.

## التشغيل المجاني عملياً

المشاريع مفتوحة المصدر مجانية ككود، لكن التشغيل يحتاج جهازاً أو VPS يبقى متصلاً بالإنترنت.

إذا كان التطبيق منشوراً على Vercel فلا يمكن وضع:

```txt
http://localhost:11434/v1
```

لأن localhost سيكون داخل Vercel وليس داخل جهازك. يجب أن تستخدم رابط خادم عام آمن مثل:

```txt
https://ai.your-domain.com/v1
```

## خيار Ollama

على الخادم:

```bash
ollama pull qwen2.5:7b-instruct
ollama serve
```

ثم اجعل Ollama متاحاً عبر reverse proxy آمن إلى:

```txt
https://ai.your-domain.com/v1
```

داخل لوحة الإدارة:

```txt
النظام: البريد والدفع → الوكيل المفتوح
AI_AGENT_PROVIDER = LOCAL_OPENAI
AI_AGENT_BASE_URL = https://ai.your-domain.com/v1
AI_AGENT_MODEL = qwen2.5:7b-instruct
AI_AGENT_API_KEY = أي مفتاح إذا وضعت حماية أمام الخادم، أو اتركه فارغاً حسب الإعداد
```

ثم اضغط:

```txt
اختبار الوكيل المحلي
```

## خيار LM Studio

LM Studio يوفر OpenAI-compatible server. شغّل النموذج ثم استخدم رابط الخادم العام عبر proxy.

الإعداد داخل المنصة هو نفسه:

```txt
AI_AGENT_PROVIDER = LOCAL_OPENAI
AI_AGENT_BASE_URL = https://ai.your-domain.com/v1
AI_AGENT_MODEL = اسم النموذج كما يظهر في LM Studio
```

## خيار vLLM

إذا لديك GPU وخادم Linux، يمكن تشغيل vLLM كخادم OpenAI-compatible ثم ربطه بالمنصة.

## ما الذي يعمل بالنموذج المفتوح المصدر الآن؟

الطبقة النصية للوكيل الذكي تستخدم النموذج المحلي أولاً:

- دردشة الطالب مع المشرف الذكي
- أسئلة القبول والدعم العام
- أسئلة الإدارة والجودة داخل صفحة الوكيل
- أسئلة المشرف البشري عن طلابه

المحادثة الصوتية الحية صوت-إلى-صوت ما زالت تعتمد على Gemini Live في هذه المرحلة، لأن تشغيل STT/TTS/Voice Streaming محلياً يحتاج طبقة إضافية لاحقاً مثل Whisper + Piper/Coqui + خادم بث صوتي.

## ترتيب الأولوية داخل المنصة

عند ضبط الوكيل المحلي:

```txt
النموذج المفتوح المصدر المحلي
ثم Gemini أو الاحتياطات الحالية إذا فشل الاتصال
```

إذا لم تضبط الوكيل المحلي:

```txt
Gemini/الاحتياطات الحالية تعمل كما كانت
```

## ملاحظات أمان

لا تفتح خادم النموذج للعامة بدون حماية. استخدم:

- HTTPS
- مفتاح API أو Basic Auth أمام الخادم
- Firewall يسمح فقط لـ Vercel أو خوادمك عند الإمكان
- Rate limiting
- مراقبة استهلاك الذاكرة والمعالج

## النماذج المقترحة كبداية

للغة العربية والدعم العام:

```txt
qwen2.5:7b-instruct
llama3.1:8b-instruct
mistral:7b
```

لآلاف الطلاب تحتاج غالباً نموذج أكبر أو GPU أقوى، أو أكثر من خادم.
