منصة رقمية متكاملة (ويب + PWA تعمل كتطبيق أندرويد) لإدارة الدبلومات المهنية والدرجات المهنية واعتماد المستشارين والمدربين — مبنية حرفياً على دليل إجراءات وشروط الالتحاق وعقد التمثيل والتفويض الدولي الخاصين بالأكاديمية.

## ✨ المزايا الكاملة

### 🌐 الموقع العام
- **الكتالوج الرسمي 2026-2027 حرفياً**: برامج الماجستير والدكتوراه المهنية (كافة التخصصات باستثناء الطب) + **15 شهادة دولية** بأسمائها الرسمية وأكوادها (GRCP، PMP، CBP-LS، CBP-IBTA، CBP-M، APHRI، CBP-S، CIPM، CCNA، OSHA، PFA، CPd-KPIs، CPd-AI، CPd-AB، CIT) + **32 دبلوماً تدريبياً** (مرقمة 16-47 في الكتالوج) بنفس ترتيب الدليل الرسمي
- **طلب الالتحاق الرسمي** بخطوات الدليل حرفياً: بيانات كاملة → رفع 4 مستندات إلزامية (شهادة، هوية، صورة، سيرة ذاتية) → الإقرار → **كود تتبع** `AACT-2026-XXXX` → سداد رسوم التقديم 30$ → دراسة الإدارة → بعد القبول سداد الرسوم الدراسية كاملة → التفعيل التلقائي
- **تتبع الطلب بالكود** مع خط زمني مرئي للحالات والفواتير
- الوكالة الدولية والاعتمادات (عقد سنة، عمولة 25%، مستحق 100$ لعضو لجنة المناقشة)
- **طلب الاعتماد بوثائقه الرسمية الإلزامية** (وفق دليل الإجراءات حرفياً): شهادة الترخيص أو مزاولة المهنة، الهوية أو جواز السفر، صور شخصية حديثة، السيرة الذاتية — لا يُقبل الطلب بدونها + **فاتورة رسوم التقديم 100$** تُسدد من نفس الصفحة وتظهر للإدارة بحالتها
- دليل المعتمدين + التحقق من الشهادات برقم تسلسلي أو QR + تواصل

### 🤖 المشرف الذكي (قسم 12.1)
- مشرف ذكاء اصطناعي **خاص بكل طالب** يعمل بالتوازي مع المشرف البشري — بمعرفة حقيقية بتخصص الطالب وبرامجه وكتبه المقررة ودرجاته ومواعيده (RAG)
- **محادثة صوتية حية بمستوى ChatGPT/Gemini**: شاشة كاملة غامرة، كرة متحركة تتفاعل مع صوت المايك فعلياً، استماع مستمر، **مقاطعة فورية (Barge-in)**، تسميات نصية حية، كتم
- **تحليل مسودات بحث التخرج** علمياً (درجة/100، قوة، منهجية، توثيق، خطوات)
- **شفافية إلزامية**: واجهة تصرّح بأنها ذكاء اصطناعي، وكل المحادثات (نصاً وصوتاً) تُؤرشف في ملف الطالب ويطّلع عليها المشرف البشري والإدارة

### 📝 نظام الامتحانات الذكي (قسم 12.2)
- الإدارة تحدد كتب كل تخصص (باسم أو **رفع PDF يقرؤه الذكاء الاصطناعي فعلياً**) + **اقتراح كتب وفق واقع التخصص عالمياً** → بعد الاعتماد تُنشر للطلاب للقراءة
- توليد امتحان لكل فصل دراسي (فصلان) من الكتب المعتمدة: **80+ سؤالاً متنوعاً** (اختياري، صح/خطأ، إجابة قصيرة، مقالي تحليلي، حالات عملية) ومدة ≥ 120 دقيقة
- **مراجعة بشرية إلزامية** (Human-in-the-loop): كل سؤال يمرّ بحالة اعتماد/تعديل/رفض قبل النشر
- مؤقت تنازلي، تصحيح فوري للموضوعي + **تصحيح ذكاء اصطناعي للمقالي مع تقرير نقاط القوة والضعف**
- **اعتراض الطالب (Appeal)** على أي تقييم → حسم بشري نهائي، ومراقبة إلكترونية اختيارية (كشف تبديل التبويبات + لقطة توثيقية)

### 🎬 قاعة المناقشة بالفيديو كونفرنس (قسم 12.3)
- قاعة **معدة أطراف داخل المنصة** (WebRTC mesh عبر إشارات الخادم): الطالب + أعضاء اللجنة متصلين من دول مختلفة + **المستشار الذكي عضواً فعلياً استشارياً**
- **شاشة تجهيز أجهزة (Pre-join)** بمعاينة الكاميرا وقائمة تحقق — كما في قاعات الاجتماعات الاحترافية
- **خوادم TURN/STUN قابلة للتهيئة** من لوحة الإدارة — اتصال مضمون عبر NAT الصارم وشبكات الشركات (دليل النشر: [`docs/turn-setup.md`](docs/turn-setup.md))
- **مشاركة الشاشة** لعرض شرائح البحث، كتم المايك، مؤشرات حالة الاتصال لكل مشارك، توقيت محلي لكل مشارك (Timezone-aware)
- **تفريغ نصي حي** + ملاحظات تحليلية فورية للجنة + **محضر جلسة تلقائي** (5 أقسام) + **تسجيل مرئي مؤرشف** في ملف الطالب
- القرار النهائي **للجنة البشرية حصراً** — والمستشار الذكي استشاري فقط (شفافية مثبتة في الواجهة)

### 💳 الدفع والإشعارات
- **دفع حقيقي جاهز للتشغيل**: Stripe Checkout + PayPal Orders (REST مباشر، بلا SDK خارجي) — أدخل المفاتيح من لوحة الإدارة وشغّل وضع LIVE فيحوَّل الطالب لصفحة الدفع الرسمية ويُعتمد السداد تلقائياً عبر **Webhook موقّع**
- وضع SANDBOX آمن (محاكاة بإيصالات فورية) + طرق فوري/Paymob/تحويل بنكي بمراجعة الإدارة
- **إشعارات بريدية آلية** (SMTP من لوحة الإدارة) بقوالب عربية RTL بهوية الأكاديمية: الترحيب، استلام الطلب بكود التتبع، الإيصالات المالية، قرارات القبول، التسجيل النهائي، نشر الامتحانات، مواعيد المناقشات، إصدار الشهادات — مع **سجل بريد** (SENT/SKIPPED/FAILED) داخل اللوحة
- آلة حالات مالية متكاملة: الرسوم (30/100/200/350/700/1000/1300$) قابلة للتعديل من اللوحة، إيصالات متسلسلة، ربط تلقائي بين السداد وحالة الطلب

### 🛡️ لوحة إدارة علمية منظمة
13 تبويباً مجمعةً في 4 أقسام وظيفية: **القبول والتسجيل** (الالتحاق بتقييم خبير الذكاء الاصطناعي، قواعد القبول لكل برنامج، الطلاب، الوكالة) · **العملية الأكاديمية** (الكتب والاختبارات، النتائج، المناقشات، سجل المشرف الذكي) · **المالية والشهادات** · **إعدادات النظام** (البريد والدفع والفيديو، الرسوم والقواعد، التدقيق، الرسائل) — مع KPIs ورسوم بيانية وسجل تدقيق شامل.

### 🤖 خبير القبول الذكي + قواعد قبول مخصصة لكل برنامج
- **قراءة صور المستندات (Vision OCR)**: صور الشهادات والهويات والسير الذاتية (JPG/PNG) يقرأها الذكاء الاصطناعي فعلياً — يستخرج نوع الوثيقة والدرجة العلمية واسم الطالب عليها والجهة المانحة والتاريخ وجودة الصورة
- **مطابقة ذكية**: يكشف تلقائياً إذا كانت الشهادة المصوّرة أقل من المطلوب (مثال: دكتوراة وصورة بكالوريوس فقط)، ويكتشف اختلاف الاسم على المستند عن الاسم المعلن، وينبّه للمستندات المزوّرة زمنياً (تواريخ مستقبلية) والمستندات المصنّفة خطأ
- **قواعد قبول مخصصة لكل برنامج** من تبويب «قواعد القبول»: الحد الأدنى للمؤهل، إلزام الماجستير للدكتوراة (أو معادلة الخبرات بحد أدنى للسنوات)، الوثائق الإلزامية (قابلة للزيادة مثل إثبات خبرات)، الحد الأدنى للعمر، وقواعد نصية حرة يقرؤها الذكاء حرفياً — وعند اختيار البرنامج في نموذج الالتحاق تظهر الشروط للمتقدم قبل التقديم
- **Human-in-the-loop**: كل التقييم يظهر للإدارة قبل زر الاعتماد — حكم ملون + درجة توافق + قائمة فحص بالمستندات + ملاحظات بدرجات خطورة + توصية تنفيذية، والقرار النهائي للإدارة حصراً
- **الوصول المباشر للوحة**: زر ذهبي بارز في الشريط العلوي + بانر فوق الرئيسية لحساب الإدارة + رابط مباشر `/?view=admin` + التحويل التلقائي للوحة بعد دخول حساب الإدارة

## 🏗️ البنية التقنية

| الطبقة | التقنية |
|--------|---------|
| الإطار | **Next.js 16** (App Router) + TypeScript 5 |
| الواجهة | Tailwind CSS 4 + shadcn/ui + Lucide — RTL عربي بالكامل + PWA |
| قاعدة البيانات | **Prisma ORM** (SQLite للتطوير — جاهز لـ PostgreSQL/MySQL بالإنتاج) |
| الذكاء الاصطناعي | طبقة `src/lib/ai.ts` قابلة للتبديل (محادثة، تصحيح، توليد أسئلة، RAG، TTS/ASR) |
| الفيديو | WebRTC mesh + إشارات عبر قاعدة البيانات + TURN/STUN مهيأ |
| الدفع | Stripe/PayPal REST + Webhook + SANDBOX |
| البريد | Nodemailer SMTP + قوالب RTL + سجل |

```
src/
├── app/api/            # 40+ مسار API (المصادقة Bearer+Cookie المزدوجة)
│   ├── admin/          # مسارات الإدارة (16)
│   ├── payments/       # checkout + webhook/stripe + config
│   ├── defense/        # القاعة + الغرفة والإشارات
│   └── webrtc/config   # خوادم ICE/TURN (للمصادقين فقط)
├── components/aact/    # 25+ مكوّن الواجهة
└── lib/                # ai.ts · mailer.ts · payments.ts · settle-payment.ts · supervisor-ai.ts ...
prisma/schema.prisma    # 25+ نموذجاً (User, Program, AdmissionApplication, Payment,
                        # ProgramExam, ReferenceBook, ThesisSubmission, DefenseRoom, EmailLog ...)
```

## 🚀 التشغيل في 3 دقائق

```bash
# 1) المتطلبات: Node 20+ أو Bun
bun install          # أو: npm install

# 2) قاعدة البيانات + البيانات الأولية (52 برنامجاً + حساب الإدارة)
cp .env.example .env # عدّل ما يلزم (كل شيء يعمل بالقيم الافتراضية)
bun run db:push
bun run db:seed

# 3) التشغيل
bun run dev          # http://localhost:3000
```

**حسابات البداية:**

| الدور | البريد | كلمة المرور |
|------|--------|-------------|
| إدارة | `admin@aact.academy` | `Admin@2026` |
| طالب | `student@demo.com` | `Demo@2026` |

> ⚠️ غيّر كلمتي المرور فور أول تشغيل حقيقي.

### النشر الإنتاجي
```bash
bun run build
bun run start
```
- غيّر `DATABASE_URL` إلى PostgreSQL/MySQL وشفّر الاتصال
- فعّل HTTPS (شرط عمل الكاميرا/المايك/WebRTC)
- أدخل مفاتيح الدفع وSMTP وخادم TURN من **لوحة الإدارة → إعدادات النظام** (أو `.env`)

## 📦 ما بعد GitHub: خطوات التخصيص

1. **الدفع الحقيقي**: لوحة الإدارة → إعدادات النظام → بوابات الدفع → أدخل مفاتيح Stripe/PayPal → حوّل الوضع إلى `LIVE` → أنشئ Webhook في لوحة Stripe يشير إلى:
   `https://your-domain.com/api/payments/webhook/stripe` (حدث `checkout.session.completed`)
2. **البريد**: نفس التبويب → أدخل بيانات SMTP → فعّل «الإرسال الفعلي» → اضغط «رسالة تجريبية»
3. **TURN**: انشر coturn وفق [`docs/turn-setup.md`](docs/turn-setup.md) → أدخل البيانات في نفس التبويب
4. **الذكاء الاصطناعي**: طبقة AI معزولة في `src/lib/ai.ts` و`src/lib/books-ai.ts` — استبدلها بمزودك (Claude/GPT/…) دون لمس بقية المنصة
